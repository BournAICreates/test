Accessibility Features

The animation system respects user preferences.

Prefers Reduced Motion

If your OS has "Reduce Motion" enabled, all animations are automatically disabled for a better experience.

Test by enabling in: System Preferences > Accessibility > Display > Reduce Motion (macOS) or Settings > Ease of Access (Windows)

JavaScript Disabled

If JavaScript is disabled, all elements gracefully degrade to their static state with full visibility and no animation delays.

Test by disabling JavaScript in DevTools Settings > Rendering

Quick Implementation Guide

1. Import Animations

<script src="js/animations.js"></script>

2. Add Attributes

<div data-animate="fade-in">Content</div>

3. Add CSS Classes

<div class="will-animate">Content</div>

4. Customize Timing

data-entrance-delay="200" data-parallax="0.5"
